## 视觉方向

**AI Body Management / Health Tech / Calm / Premium**

核心视觉：
- Primary：#10B981
- AI：#3B82F6
- 页面背景：#F7F8FA
- 白色卡片
- 16–20px 圆角
- 4px spacing base

## 重要原则

1. 自动采集优先，手动记录兜底
2. Body Score 是核心视觉资产
3. AI 使用统一视觉语言
4. 数据必须可解释
5. AI 估算必须标注
6. 所有异步功能必须有状态
7. 微信小程序以 375px 为设计基准

## 注意

这是 MVP 的视觉定稿基线，Logo、品牌字体和最终图标库仍可以在品牌确认后替换，但不应该再改变信息架构和核心交互。
