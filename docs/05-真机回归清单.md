# 真机回归清单(2026-10 收尾批次)

> 这一轮上线前的真机过检清单,覆盖 2026-10 全部收尾工作:营养素目标环、平台期检测、
> 常吃食物保存、步数目标、健康数据导出、睡眠记录、周报推送、首页能量收支环、**深色模式整批**。
> 开发者工具验不了的东西(授权弹窗、订阅消息实发、系统深色切换、原生 tabBar 渲染)都在这儿。
>
> **用法**:真机开体验版,逐条勾。每条都写了前置条件 → 操作 → 预期;预期没达成就在条目后补一句实况,
> 别只打叉 —— 回头修的人要靠那句话定位。
>
> **环境**:iOS + Android 各一台;两台都要过「深色模式专项」;
> 订阅消息那节需要后台已配好模板(见文末「上线前置」)。

## 1. 深色模式专项(新面,风险最高)

系统切深色: iOS 设置→显示与亮度→深色 / Android 下拉快捷开关(或系统设置→显示→深色模式)。切完**杀掉小程序重新打开**(冷启动才拿到新主题),逐页走:

- [ ] 首页:整体暖黑底、卡片深灰绿;「今日完成」环亮苔绿;摄入/消耗两枚小环清晰可见,环心百分数能读
- [ ] 首页页头山水装饰图:深色下变暗(约两成透明度的纹理),**不是**一大块发白的图
- [ ] 日期条:选中日「今天」那格是亮苔绿底 + 深色字,不是白字糊在亮绿上
- [ ] 记录/训练/趋势/我的 四个 tab:tabBar 深色底、选中图标是亮绿色(不是沉进底色的墨绿)
- [ ] tabBar 顶上那条发丝线在深色下可见(浅色模式是深色线,深色模式应为浅色线)
- [ ] 体重曲线卡(首页)、趋势页各折线图:线条、纵轴刻度、目标虚线、末点气泡全部读得清;末点气泡字是深色(气泡底是亮绿)
- [ ] 周报页:顶部评分卡是亮苔绿渐变 + 深色说明字(不是白字糊在亮绿上)
- [ ] 我的页:hero 渐变亮绿,「目标胶囊」和用户 id 是深色字
- [ ] 训练 tab:该练那卡的浅绿渐变变成深色渐变;页脚那句引言卡也是深色
- [ ] 训练分包任意页(如动作库):底部浮动导航选中格图标亮绿,和原生 tabBar 同一色
- [ ] 本地教练页:顶栏深色(不是一条白带)
- [ ] 饮食记录页:拍照识别中那张卡是深蓝灰底
- [ ] 记录页:运动/体重那列图标底是暖深底(和旁边的绿有温差)
- [ ] **切回浅色**:杀进程重开,所有页面恢复暖纸底;再来回切两次,无残留混色
- [ ] 下拉刷新的三个点在深色下可见(浅色模式深点、深色模式浅点)

**已知口径(不是 bug,别报)**:分享出去的卡片图恒为浅色(收到的人永远在浅色聊天界面看);装饰山水在深色下是「压暗」不是重画的深色版(深色装饰图是另一个待办)。

## 2. 首页

- [ ] 摄入热量行:数字 + 「/ 目标 kcal」+ 右端小环;点整行进饮食页
- [ ] 摄入超过目标当天:小环走满一圈、环心数字如 `112%` 且为琥珀色(不是绿色也不封顶成 100%)
- [ ] 没记录/没目标的新号:两枚小环是灰轨道 + 环心「—」,不是 0%
- [ ] 消耗行:点进去(身体资料不全时先弹资料编辑,补全后直接进运动页)
- [ ] 体重行:有变化时涨跌胶囊(涨=琥珀、降=绿);点进体重数据页
- [ ] 近 7 天体重卡:曲线 + 末点「77.8kg」式气泡;只有一条体重时曲线退化为单点 + 气泡仍在

## 3. 记录链路(吃/动/称/睡/水)

- [ ] 饮食页顶部营养素环:热量/碳水/蛋白/脂肪对目标的比例,记一餐后环有变化
- [ ] 「我的」食物:加进一餐后能「存为常吃」,下次搜索里出现、可直接加入
- [ ] 运动页记一条运动,首页消耗环当天更新(基础代谢+日常+运动 三段构成在净值行可见)
- [ ] 力量训练计入消耗:练完一堂,运动页手动那桶多一条训练来源记录(不可编辑删除)
- [ ] 速记页睡眠卡:滑动睡眠时长,保存后首页/趋势能看到
- [ ] 步数目标:设置里改一个非默认值,首页步数进度条的分母跟着变

## 4. 趋势 / 周报

- [ ] 趋势页各曲线区间切换(7 天/30 天/90 天)后点选读数正常、纵轴刻度随区间变
- [ ] 平台期提示:造一段体重基本不动的数据(连记多天同一体重),趋势/体重页出现平台期说法;波动明显的账号不出
- [ ] 周报页翻往期、重新生成;报告生成失败时底部推送开关仍可用(它在条件渲染外面)

## 5. 订阅消息(需要后台模板,见文末)

- [ ] 训练 → 提醒页:开开关弹授权,「总是保持以上选择」勾与不勾各试一次;允许后显示剩余额度,再点一次额度 +1
- [ ] 周报页底部推送开关:同上流程;模板没配时开关禁用 + 文案如实说明「推送模板还没配好」
- [ ] 周报推送实发(开发陪同):后台把某测试号的发送时间调到近处,确认真机收到订阅消息、点进去落在周报页
- [ ] 拒绝授权后:文案如实(「没拿到微信授权」),开关不变成开着

## 6. 数据出口

- [ ] 我的 → 数据导出:体重/饮食各导一次,收到文件、内容能打开、行数和页面记录数对得上
- [ ] 分享训练计划:卡片图生成、转发出去后接收方看到的是浅色卡(口径见上)

## 7. 埋点抽查(开发陪同项)

后台按事件名查最近上报,逐个确认**有数**:

- [ ] `weekly_push_view` / `weekly_push_toggle {enabled,grants}`(周报页)
- [ ] `quick_sleep_save {hours}`(速记睡眠卡)
- [ ] `custom_food_save`(我的食物「存」)
- [ ] `health_data_export {kind,rows}`(数据导出)
- [ ] `datasource_sync_success` / `datasource_sync_error`(微信运动同步一次,两边至少有一边有数)

## 8. 老功能过一遍(改动波及处)

- [ ] 冷启动启动遮罩:浅色纸底/深色墨底各看一次,6 秒兜底消失
- [ ] 首页「练到一半」卡:出现、接着练、放弃(带确认)三条路都通
- [ ] 训练页开始一堂,组间休息计时、暂停继续正常;练完写卡路里回写不报错
- [ ] 所有 tab 页与二三级页在深浅两种模式下无白底残留、无不可读文字(快速滑动目检即可)
