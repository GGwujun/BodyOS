# Body OS｜交互与状态规范

## AI 识别状态
```text
idle
→ uploading
→ parsing
→ need_confirm
→ confirmed
→ failed
```

## 数据同步状态
```text
disconnected
→ connecting
→ connected
→ syncing
→ synced
→ error
```

## 空状态
不要只显示“暂无数据”，要告诉用户下一步：
- 未记录饮食 → [记录第一餐]
- 未连接数据 → [连接运动数据]
- 无体重 → [记录体重]

## 错误
错误信息需要：
1. 发生了什么
2. 是否影响数据
3. 下一步怎么处理

## AI 建议
优先：
- 结论
- 依据
- 行动

避免长篇输出。

## 删除
删除健康数据需要二次确认，并说明影响。
