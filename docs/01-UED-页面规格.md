# Body OS｜UED 页面规格 v0.2

## 页面尺寸
- 微信小程序优先：375 × 812 作为设计基准
- 组件使用 8pt spacing system
- 卡片圆角 16–20px
- 页面左右安全边距 16px

## 01 Home
### 目标
3 秒理解今日状态，10 秒知道下一步。

### 信息层级
1. Body Score
2. 摄入 / 消耗 / 净值
3. 活动
4. 营养
5. AI 建议

### 关键交互
- 点击 Body Score → 今日详情
- 点击摄入 → 饮食详情
- 点击活动 → 运动详情
- 点击 AI 建议 → AI Coach

## 02 Record
- 三个快速入口：饮食 / 运动 / 体重
- 自动数据区域显示同步状态
- 最近记录支持编辑

## 03 Food
- 文本输入
- 图片入口
- AI 解析 loading

- 营养汇总

## 04 Exercise
