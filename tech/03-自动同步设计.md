# Body OS｜自动同步设计

## Adapter

每个 provider 实现统一接口：

```ts
interface HealthProviderAdapter {
  connect(): Promise<void>
  disconnect(): Promise<void>
  sync(cursor?: string): Promise<SyncResult>
  normalize(raw: unknown): NormalizedRecord[]
}
```

## 同步流程

```text
Provider
→ Fetch Incremental
→ Persist Raw
→ Normalize
→ Validate
→ Deduplicate
→ Upsert Canonical
→ Recalculate Daily Summary
→ Update Cursor
```

## 幂等

唯一键建议：
- provider
- external_id
- user_id

## 重试
指数退避，限制最大重试次数。

## 数据冲突
保留 raw；canonical 选择主来源；不删除原始来源。
